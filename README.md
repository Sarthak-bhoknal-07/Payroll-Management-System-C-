# Payroll Management System (C++)

## 📌 Project Overview
The Payroll Management System is a console-based application developed in C++ to manage employee records and automate salary processing. The system performs salary calculations with deductions, generates payslips, and maintains persistent employee data using file handling.

This project demonstrates practical implementation of Object-Oriented Programming, data processing, and modular software design.
---
## 🎯 Features
- Add, update, delete employee records
- Search employee by ID
- Automated salary calculation with bonus and tax deduction
- Payslip generation with salary breakdown
- File-based data storage using structured format
- Payroll summary report generation
- Menu-driven console interface
---
## 🛠 Technologies Used
- C++
- Object-Oriented Programming (OOP)
- STL Containers (vector, file streams)
- File Handling
- Modular Programming
